## 💡 구글 애드센스 신청 방법 가이드
1. [Google AdSense](https://adsense.google.com/) 가입 후 본 사이트 URL(`https://am4-realbj.github.io/ai-product-builder-week1/`)을 사이트로 등록합니다.
2. 발급받은 본인의 애드센스 게시자 코드(예: `ca-pub-XXXXXXXXXXXXXXXX`)를 `index.html` 상단의 메타 태그 주석을 해제하고 입력합니다:
   ```html
   <meta name="google-adsense-account" content="ca-pub-본인_게시자_ID">
   ```
3. `git commit -am "chore: add adsense publisher id"` 후 `git push origin main` 하시면 사이트 검토가 시작됩니다.
